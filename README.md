# EconoCausal: Dynamic Pricing via Double Machine Learning

## Project Overview
EconoCausal is a Data Science and Machine Learning project focused on estimating the causal impact of pricing changes on product demand and sales using Double Machine Learning (DML).

## Objectives
- Collect and preprocess relevant datasets.
- Perform Exploratory Data Analysis (EDA).
- Develop machine learning models.
- Estimate the causal effect of pricing changes.
- Evaluate and document the results.

## Technologies
- Python
- Pandas
- NumPy
- Scikit-learn
- Double Machine Learning
